# Поиск видео для копицентров Copy.ru

Портативная программа для Windows 10 и 11. Ищет короткие ролики о полиграфическом производстве на бесплатных видеостоках, показывает только ролики с подходящей лицензией и скачивает выбранные вместе с файлом лицензии.

## Установка

1. Скачайте `CopyVideoFinder-…-windows.zip` со страницы [Releases](../../releases).
2. Распакуйте архив в любую папку (можно на флешку). Права администратора не нужны.
3. Запустите `CopyVideoFinder.exe`.

Программа ничего не пишет в реестр и системные папки. Настройки, ключи API, кэш, журнал и скачанные ролики хранятся в папке `Данные` рядом с `CopyVideoFinder.exe`. Чтобы удалить программу, удалите её папку.

## Каталог

Понравившийся ролик — кнопка **В каталог — лицензию проверил**: он сохранится в каталоге и привяжется к услуге, по которой искали. Неподходящий — **Не подходит**: в поиске он больше не появится. Скачанные ролики тоже попадают в каталог, номер в каталоге — в начале имени файла.

Вкладка **Каталог**: слева услуги с числом роликов и покрытием («1 из 3» — сколько засчитанных роликов из нужных), в середине список с поиском и фильтром отметок, справа карточка ролика — можно поправить название, отметку, подтвердить лицензию, привязать ролик к другим услугам и указать степень соответствия (точное, частичное, смежный процесс, только готовая продукция), оставить комментарий. В покрытие засчитываются ролики с подтверждённой подходящей лицензией и степенью не «только готовая продукция».

## Обновления

При запуске программа проверяет, вышла ли новая версия на GitHub, и предлагает обновиться: «Обновить», «Позже» или «Пропустить эту версию». Обновление скачивается, проверяется по контрольной сумме, программа закрывается и через несколько секунд запускается уже новой версией. Настройки, ключи и скачанные ролики сохраняются. Проверить вручную — **Справка → Проверить обновления**; отключить проверку — в настройках.

## Ключи API

Меню **Файл → Настройки**:

| Площадка | Ключ | Где взять |
| --- | --- | --- |
| Pixabay | нужен, бесплатный | https://pixabay.com/api/docs/ (после входа в аккаунт) |
| Coverr | нужен, бесплатный (50 запросов в час) | https://coverr.co/developers |
| Vimeo | нужен личный токен (права public) | https://developer.vimeo.com/apps — создать приложение, затем токен |
| Wikimedia Commons | не нужен | — |
| Pexels | нужен, бесплатный | https://www.pexels.com/api/ (выдача новых ключей сейчас приостановлена Pexels) |

Площадки без ключа просто пропускаются. Vimeo ищет только среди роликов с лицензиями Creative Commons; если Vimeo не даёт ссылку на файл, ролик можно скачать на его странице (если автор разрешил).

## Как пользоваться

1. Начните вводить название услуги, например «ламинация» или «брошюровка на пружину», и выберите её из подсказок. Можно ввести и свой запрос — на русском или на английском.
2. Программа ищет на всех площадках сразу по русским и английским фразам услуги. В выдаче только ролики длиной 5–45 секунд, не ниже HD и с лицензией «Разрешено» или «Разрешено с атрибуцией».
3. Нажмите на ролик — он воспроизведётся справа, там же автор и лицензия.
4. Выберите качество (по умолчанию — лучшее до Full HD) и нажмите **Скачать**. Ролик сохранится в `Данные/Видео/Категория/Услуга/`, рядом — текстовый файл с лицензией, автором, ссылками и готовым текстом атрибуции.

Ролики с Wikimedia Commons в формате WebM автоматически конвертируются в MP4 (FFmpeg входит в программу).

Для лицензий «с атрибуцией» на экране нужно показывать титр с автором — текст есть в файле лицензии. Окончательное подтверждение лицензии — за пользователем.

## Для разработчика

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
pytest
pyinstaller build.spec --noconfirm
```

FFmpeg для разработки: положите `ffmpeg.exe` и `ffprobe.exe` в папку `ffmpeg` в корне проекта или установите их в PATH.

Сборка для Windows идёт в GitHub Actions (`.github/workflows/build.yml`). Вкладка **Actions → Сборка для Windows → Run workflow**: без версии — ZIP в артефактах запуска; с версией (например, `0.4.1`) — ещё и выпуск в Releases с тегом `v0.4.1`.

Правила проекта и устройство кода — в [CLAUDE.md](CLAUDE.md), полное ТЗ — по ссылке оттуда.
