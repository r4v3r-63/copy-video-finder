# Вход в VK Видео

Поиск роликов в VK программа делает через официальный VK API. Для этого нужен вход в ваш аккаунт VK.
Пароль программа не видит: вы входите на сайте VK в своём браузере, а программа получает только
ключ доступа. Он хранится только на вашем компьютере — в папке `Данные` рядом с программой —
и продлевается сам.

## 1. Создайте своё приложение VK ID (один раз, около 5 минут)

1. Откройте [id.vk.com](https://id.vk.com) → «Мои приложения» → «Создать приложение».
2. Название — любое. Платформа — только **Web**.
3. **Базовый домен:** `oauth.vk.com`. **Доверенный Redirect URL:** `https://oauth.vk.com/blank.html`.
4. Способы быстрого входа не нужны — «Настроить позже».
5. Скопируйте **ID приложения** (число) со страницы приложения.

Защищённый и сервисный ключи приложения программе не нужны — никому их не передавайте.

## 2. Войдите из программы

1. «Файл → Настройки», строка «VK Видео»: вставьте ID приложения и нажмите **«Войти в VK»**.
   Окно настроек не закрывайте.
2. В браузере войдите в VK и разрешите доступ к видео.
3. Браузер перейдёт на страницу с адресом `https://oauth.vk.com/blank.html?code=…`
   (страница может быть пустой — так и задумано). Скопируйте этот адрес целиком.
4. Вставьте адрес в поле под кнопкой и нажмите «Сохранить». Готово: в поиске появится площадка «VK Видео».

Выйти — кнопка «Выйти» в той же строке настроек. Отозвать доступ можно и в VK:
«Настройки → Приложения и сайты».

Если VK показывает ошибку вместо входа — пришлите её снимок.
