# Вход в VK Видео

Поиск роликов в VK программа делает через официальный VK API. Для этого нужен вход в ваш аккаунт VK.
Пароль программа не видит: вы входите на сайте VK в своём браузере, а в программу попадает только
ключ доступа (токен). Он хранится только на вашем компьютере — в папке `Данные` рядом с программой.

## 1. Создайте своё приложение VK (один раз, около 5 минут)

1. Откройте [dev.vk.com](https://dev.vk.com) и войдите своим аккаунтом VK.
2. Перейдите в раздел «Мои приложения» и нажмите «Создать приложение».
3. Название — любое, например «Поиск видео Copy.ru». Платформа — **Standalone-приложение**
   (если такого пункта нет — «Веб» или «Desktop»).
4. После создания откройте настройки приложения и скопируйте **ID приложения** (число).

## 2. Войдите из программы

1. В программе: «Файл → Настройки», строка «VK Видео». Вставьте ID приложения и нажмите **«Войти в VK»**.
2. В браузере откроется страница VK: войдите и разрешите доступ к видео.
3. Браузер перейдёт на страницу с адресом `https://oauth.vk.com/blank.html#access_token=…`
   (страница может быть пустой — так и задумано). Скопируйте этот адрес целиком из адресной строки.
4. Вставьте адрес в поле под кнопкой и нажмите «Сохранить». Готово: в поиске появится площадка «VK Видео».

Выйти — кнопка «Выйти» в той же строке настроек. Отозвать доступ можно и в VK:
«Настройки → Приложения и сайты».

Если VK показывает ошибку вместо входа — пришлите её снимок: VK иногда меняет правила для новых приложений.
