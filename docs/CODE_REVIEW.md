# Ревью перед выпуском 0.24.0 — 20.10.2026

Пока запуск Windows-выпуска блокировался сетевым доступом к GitHub API, ревью и исправления
выполнены до публикации. Исходный порядок «релиз, затем ревью» изменён, чтобы найденные
ошибки не попали в готовящийся архив.

## Область проверки

- Запуск, настройки, пути, сохранение пользовательских данных и миграции справочника/каталога.
- Построение запросов, тематический отбор, лицензии, покрытие, история и пакетный поиск.
- Источники, HTTP-кэш и лимиты, VK ID и обновление ключей; ручное добавление ссылок.
- Очередь скачивания, докачка, FFmpeg, кадры, шоурил, завершение потоков.
- Каталог, массовые действия, фильтры, просмотр и руководство.
- CSV/XLSX/HTML/PDF/M3U, импорт, автообновление, PyInstaller и Windows-workflow.

Использованы чтение кода, Ruff, полный pytest, сохранённые ответы площадок, настоящие SQLite
и FFmpeg, отдельные проверки интерфейса Qt без экрана. Новые регрессии — `tests/test_code_review.py`;
тесты новых возможностей — `test_backup.py`, `test_manual.py`, `test_catalog_actions.py`,
`test_result_filters.py`, `test_guide.py`.

## Найдено и исправлено

| Приоритет | Воспроизводимая проблема | Исправление и проверка |
| --- | --- | --- |
| Высокий | Шоурил блокировался на чтении stdout молчащего FFmpeg, отмена не выполнялась | Неблокирующее чтение файла прогресса и опрос процесса; тест запускает молчащий дочерний процесс и проверяет его завершение и очистку временного видео |
| Высокий | Докачка могла склеить ответ 206 с неверным началом диапазона | Проверяются Content-Range, начало, конец и размер ответа; некорректный ответ не заменяет итоговый файл |
| Высокий | Автообновление принимало старый выпуск без SHA-256 | Установка требует контрольную сумму и HTTPS; старые выпуски доступны для ручного скачивания со страницы, неверное имя файла отклоняется до записи |
| Средний | Изменившиеся условия лицензии сохраняли прежнее подтверждение пользователя | При изменении названия, URL или статуса лицензии сбрасывается только подтверждение; отметки, название, комментарий и привязки сохраняются. Скачивание не подтверждает лицензию повторно |
| Средний | Проверка ссылок игнорировала обновлённые сведения о лицензии из API | Сведения обновляются для той же пары площадка/ID; изменившиеся условия требуют новой ручной проверки |
| Средний | Повтор скачивания по Retry-After не реагировал на отмену | Ожидание через Event.wait; отменённое задание не отправляет новый запрос и не заменяет файл |
| Средний | Разные экземпляры VK могли повторно использовать одноразовый ключ обновления | Общая блокировка по приложению/устройству и чтение последних сохранённых ключей; тест проверяет одно обновление для двух экземпляров |
| Средний | Одновременные записи настроек использовали общий временный файл | Сериализация записи и уникальные временные файлы с атомарной заменой; тест конкурентной записи и ошибки замены |
| Средний | Настройки с JSON-массивом или неверными типами нарушали запуск | Проверка структуры и типов, возврат допустимых значений по умолчанию без удаления исходного файла |
| Средний | Повреждённый пользовательский словарь мешал запуску и редактору | Используется встроенный словарь, повреждённый файл сохраняется до явного действия пользователя |
| Средний | Перенос старого справочника мог заменить предыдущую резервную копию той же версии | Подбирается свободное имя; тест сохраняет обе копии |
| Средний | Временный журнал SQLite мог исчезнуть во время обхода резервной копии | Журналы и незавершённые атомарные записи исключаются до открытия файлов; тест воспроизводит исчезновение журнала |
| Средний | CSV с NaN/Infinity приводил к исключению при преобразовании размеров | Неограниченные и неопределённые числа не импортируются в числовые поля |
| Средний | Адрес площадки внутри чужого пути или параметра принимался за настоящую площадку | Проверяются настоящий hostname и путь; отдельные тесты для поддельных ссылок стоков и YouTube |
| Низкий | Не учитывались зарезервированные имена файлов Windows | CON/PRN/AUX/NUL/COM1–9/LPT1–9 получают безопасный префикс |
| Низкий | Окно, PDF и «О программе» ссылались на отсутствующий logo.png | Используется существующий logo.svg; рендеринг проверен через Qt |
| Низкий | Отсеянные «не по теме» могли оказаться выше релевантных роликов с отрицательным рейтингом | Признак дополнительной выдачи отделён от рейтинга; такие карточки располагаются после основной выдачи |

Запись настроек, словаря и справочника теперь атомарна; ошибка не оставляет половину JSON-файла.
Проверки лицензий используют сохранённую HTML-фикстуру и не обращаются к сети.

## Результаты и ограничения

Локально: Ruff без ошибок, 458 passed, 1 skipped. Пропущен тест командного файла автообновления,
который выполняется только в Windows. Проверены также создание архива через меню и полный
путь добавления ссылки через диалог с выбором группы и обновлением покрытия.

Новые исходники отправляются в main. Запуск Actions, Windows-сборка и публикация требуют
доступа к api.github.com; домен сохранён в черновике сетевых настроек среды. До успешного
workflow нельзя считать Windows-архив 0.24.0 выпущенным.

Остаются внешние проверки: живой вход VK, реальные ответы площадок с пользовательскими
ключами, запуск готового дистрибутива на чистой Windows 10/11 и с флешки. Никакие ключи,
блокировки или лимиты для тестирования не обходились.
