# Состояние проекта по ТЗ — 21.10.2026, версия кода 0.25.3

В 0.24.0 выпущены ручное добавление по ссылке, резервная копия «Данных», массовые действия и фильтры каталога, сортировка и фильтры выдачи, показ отклонённых и встроенное руководство. [Windows-выпуск 0.24.0 опубликован](https://github.com/r4v3r-63/copy-video-finder/releases/tag/v0.24.0), тег — коммит `99897ad`. Windows-тесты, сборка и проверка запуска успешны; опубликованный ZIP проверен по SHA-256 и CRC, руководство и FFmpeg входят в поставку.

После выпуска настроена автоматическая публикация следующих версий: повышение `__version__` и пуш в `main` → успешные Ruff и тесты → Windows-сборка того же SHA → выпуск с прежними именами ZIP и SHA-256. Без изменения версии релиз не запускается; опубликованные версии защищены от перезаписи. Ручной запуск остаётся для повторной попытки после сбоя. Выбор версии проверяется 20 тестами на локальной истории git без сети; автовыпуск впервые используется для 0.24.1.

В 0.24.1 по решению пользователя исключён «Перевод документов»: из подсказок, пакетного поиска и каталога услуг, включая старые пользовательские копии справочника. Ролики остаются в каталоге; снимаются только привязки к исключённой услуге. Осталось 375 услуг в 87 группах и 20 разделах.

Для 0.25.0 обновлено оформление по согласованному макету: светлый Fluent и тёмная медиатека, карточки роликов с названием и меткой лицензии, контурные значки, мягкое выделение, обновлённая панель просмотра и таблицы. Смена темы сохраняет выбранный ролик и пользовательские отметки; основные предупреждения о правах видны и при свёрнутых сведениях. Реальные снимки программы в обеих темах — `docs/screenshots/`, примечания выпуска — `docs/release-notes/0.25.0.md`.

В 0.25.1 исправлена подпись карточки «Не по теме»: используется отдельная отметка причины отсеивания, а не оценка релевантности, которая может быть отрицательной и у подходящего по теме ролика. Сортировка и фильтры не меняются; случай проверяется на сохранённой фикстуре без сети.

В 0.25.2 по обращению пользователя исправлены потеря превью из отдельных записей Яндекс Видео и повторные запросы общей картинки. Без встроенного просмотра кнопка плеера открывает исходный сайт; такой же переход доступен после ошибки видео. Отсутствующая картинка и ошибка её загрузки различаются, пустые элементы управления скрыты. Полное наличие картинок у внешних сайтов не гарантируется: адреса не выдумываются, отказы и ограничения не обходятся. Регрессии — `tests/ui/test_previews.py`, без сети.

В 0.25.2 добавлена обязательная проверка горизонтального содержимого: вертикальный/квадратный кадр с чёрными полями не подходит. Анализируются полезная область превью и три кадра видео; горизонтальная обложка сама по себе ничего не подтверждает. Локальный файл проверяется после скачивания и при повторном использовании по фактической длительности файла, в том числе после обрезки. Непроверенные записи не входят в покрытие, M3U и шоурил; для роликов только на сайте есть явное подтверждение после просмотра. Старые записи и файлы сохраняются, но требуют новой проверки содержимого. Фикстуры — `tests/fixtures/orientation/`, регрессии — `tests/services/test_orientation.py` и `tests/ui/test_previews.py`, без сети.

В 0.25.3 кнопка «Не подходит» выделена красной заливкой и белым текстом в обеих темах. Описаны состояния наведения, нажатия, фокуса и неактивности; действие отклонения не меняется.

Готовится 0.25.4: исходная страница видеоплощадки автоматически открывается внутри панели, если нет прямой ссылки или QMediaPlayer сообщил ошибку. Внешний браузер — только по отдельной кнопке. Реальный локальный WebM в Linux воспроизводится; для Windows добавлена отдельная проверка H.264 в переносимом WebView2, включая собранный EXE. Вход на сайты — в приватном сеансе, без JS-моста к Python; runtime входит в поставку, объём ZIP увеличится. Первый реальный запуск Windows выявил сбой интеграции; добавлены диагностика native-компонента и UTF-8 для диагностического вывода Windows, ошибка исправляется до выпуска. Публикация ещё не завершена.
