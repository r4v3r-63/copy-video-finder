# Copy.ru 0.24.0

- Добавление ролика в каталог по ссылке с получением сведений, выбором услуги и проверкой лицензии.
- Резервная копия всей папки «Данные» в ZIP с корректными снимками открытых баз SQLite.
- Массовые действия в каталоге: отметки, скачивание выбранных, копирование и проверка ссылок.
- Дополнительные фильтры каталога по площадке, лицензии, соответствию, дате и наличию файла.
- Сортировка и фильтры выдачи, скрытие уже добавленных и показ ранее отклонённых роликов.
- Встроенное руководство пользователя, доступное без интернета из меню «Справка».
- Исправления по ревью: отмена FFmpeg и повторов скачивания, проверка диапазонов докачки,
  атомарное сохранение данных, обновление ключей VK, обработка повреждённых настроек и словаря.
- После изменения условий лицензии требуется новое подтверждение пользователя.
- Автообновление устанавливает только архивы с опубликованной контрольной суммой SHA-256.

Перед обновлением рекомендуется сохранить копию «Данных». Резервный ZIP содержит ключи
и токены из настроек; храните его приватно. Внешняя папка скачанных роликов в копию не входит.

Скачайте `CopyVideoFinder-v0.24.0-windows.zip`, распакуйте полную папку и запустите
`CopyVideoFinder.exe`. Для существующей установки доступно автообновление.
