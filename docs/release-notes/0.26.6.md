# 0.26.6

- В «Загрузке по ссылке» добавлена параллельная загрузка: параметр «Одновременно» от 1 до 8 файлов, по умолчанию 4. Пауза, отмена и корректное закрытие действуют на всю очередь.
- Новый режим «Все найденные» скачивает все подходящие новые ролики со всех полученных страниц. Число роликов и режим «Все на странице» сохранены. Реальные ограничения API сохраняются: Pixabay предоставляет до 500 результатов запроса.
- Исправлено автообновление: установщик Windows PowerShell подтверждает запуск до закрытия программы, проверяет установленный EXE по SHA-256 и сохраняет ошибки в «Данные/update.log». Неудачная установка не удаляется и не маскируется запуском старой версии.
- Проверяется замена реального работающего EXE и перезапуск с сохранением настроек и роликов, включая кириллицу и специальные символы в пути. В финальной сборке задан UTF-8 для русской диагностики.

Если прежняя версия скачивает обновление и закрывается без установки, этот выпуск нужно один раз распаковать вручную в новую папку. При закрытой программе перенесите туда папку `Данные` из старой версии и запускайте новый `CopyVideoFinder.exe`.
