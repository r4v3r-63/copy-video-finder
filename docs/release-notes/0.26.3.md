# 0.26.3

- Аниме, мультфильмы и анимация исключаются из обычного поиска и «Загрузки по ссылке» по типу видео, названию и тегам.
- Pixabay запрашивается с `video_type=film`; конфликтующий тип в ссылке заменяется с предупреждением.
- Фильтр применяется до выбора и формирования очереди. Ролики без соответствующих меток могут потребовать ручной проверки; визуального распознавания нет.
