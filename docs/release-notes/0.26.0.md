# 0.26.0

- Новый раздел «Загрузка по ссылке»: выдача Pixabay и Internet Archive, превью и статистика.
- Диапазон секунд с независимыми границами, ориентация и качество; фильтры работают без повторных API-запросов.
- Индивидуальная загрузка Pixabay, разрешённые пакетные действия Internet Archive, пагинация и исключение дублей.
- Пауза, продолжение, отмена, исходные файлы и проверка целостности, TXT лицензии и JSON метаданных.
- Скачивания нового раздела не добавляются в каталог услуг автоматически. Ограничения API, включая отсутствие time_lapse, показаны явно.
