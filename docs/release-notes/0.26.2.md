# 0.26.2

- Обязательный параметр «За один запуск»: положительное число видео или «Все на странице».
- Выбор конкретной страницы API; режим всей страницы не включает соседние страницы.
- Числовой предел применяется после фильтров и выбора; завершённые в сеансе ролики повторно не занимают лимит.
- Пакетный выбор и загрузка включены также для Pixabay по новому решению пользователя. Ограничения API и обработка HTTP 429 сохранены; очередь запускается только вручную.
