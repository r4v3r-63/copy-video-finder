# 0.26.1

Все возможности загрузки по ссылке из 0.26.0, а также исправления после ревью:

- Сетевые ошибки выдачи не показывают служебный URL с API-ключом.
- Кнопка отмены отправляет запрос без ожидания сетевого таймаута в интерфейсе; при закрытии потоки по-прежнему дожидаются завершения.
- Имена новых файлов устойчивы к совпадению обрезанных длинных ID. Скачивания 0.26.0 распознаются и не повторяются.
