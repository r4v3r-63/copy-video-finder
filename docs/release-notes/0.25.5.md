# 0.25.5

- Скачивание внутри программы со страниц поддерживаемых видеоплощадок, даже когда поиск не дал прямой файл.
- Автоматический выбор до Full HD/4K, загрузка сегментов и объединение изображения со звуком.
- Поддержка входа через приватный встроенный просмотр; чужие браузеры не используются.
- Очередь, массовое скачивание из каталога, отмена, проверка горизонтального содержимого и файл лицензии сохранены.
- yt-dlp и Deno входят в переносимую поставку. DRM, платный доступ и ограничения площадок не обходятся.
