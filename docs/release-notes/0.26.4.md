# 0.26.4

- В папках скачанных роликов остаются только готовые MP4. Лицензии и метаданные сохраняются отдельно в «Данные/download-info», временные и повреждённые файлы — в «Данные/download-jobs».
- Служебные файлы прежних версий автоматически переносятся при следующем скачивании в ту же папку. Посторонние файлы не удаляются; проверка повторных скачиваний по SHA-256 сохранена.
- Другие контейнеры в «Загрузке по ссылке» переносятся в MP4 без перекодирования, если потоки совместимы. Простого переименования расширения нет; для несовместимых потоков выводится ошибка.
- Готовый MP4 появляется после проверок. Ошибка и отмена не заменяют ранее скачанный файл, докачка хранится отдельно от папки видео.
