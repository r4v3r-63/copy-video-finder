# Версия 0.25.4

Ролики без прямой ссылки на файл открываются в панели программы через плеер/страницу площадки. После ошибки обычного плеера включается тот же встроенный просмотр. Внешний браузер открывается только по отдельной кнопке.

В Windows используется WebView2 с поддержкой H.264. Официальный переносимый runtime включён в поставку, его подпись проверяется при сборке. Установка не требуется, архив стал больше. Вход на площадки выполняется внутри панели в приватном сеансе; пароли и автозаполнение не сохраняются. При смене ролика и закрытии программы прежнее воспроизведение останавливается.

Если площадка ограничивает доступ, требует вход или запрещает воспроизведение, программа не обходит её ограничения. Проверка горизонтального содержимого и лицензий сохраняется; красная кнопка «Не подходит» из 0.25.3 тоже включена.
