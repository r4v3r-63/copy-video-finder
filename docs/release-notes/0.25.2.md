# Версия 0.25.2

- Исправлена потеря картинки Яндекс Видео, если описание и превью пришли отдельными записями, а также превью в записи самого ролика.
- Общая картинка загружается один раз за поиск и появляется во всех соответствующих карточках, включая добавленные позже. Отказы не вызывают повторных запросов для каждой карточки.
- Для роликов без встроенного просмотра кнопка плеера теперь активна: **Смотреть на сайте** открывает исходную страницу. Такой переход предлагается и после ошибки воспроизведения.
- Скрыты неработающие шкала времени, пустой выбор качества и недоступный блок кадров у роликов, которые смотрят на сайте.
- Подписи различают картинку, не предоставленную площадкой, и ошибку её загрузки. Недостающие адреса не конструируются.
