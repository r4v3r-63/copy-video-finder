# 0.26.5

- Исправлен запуск установщика обновлений: вместо cmd.exe используется встроенный Windows PowerShell с поддержкой кириллицы, пробелов и специальных символов в пути.
- Программа закрывается через штатное завершение окна только после подтверждения запуска установщика. Если установщик не запустился, окно остаётся открытым с сообщением об ошибке.
- После копирования проверяется SHA-256 фактически установленного EXE. Ошибки больше не маскируются повторным запуском старой версии.
- Незавершённая установка не удаляется при следующем запуске. Журнал — `Данные/update.log`, ошибки запуска — `Данные/update/installer-start.log`.
- В Windows CI добавлена проверка замены реального работающего EXE, автоматического перезапуска и сохранения настроек и видео.

Если прежняя версия скачивает обновление и закрывается без установки, этот выпуск нужно один раз распаковать вручную в новую папку. При закрытой программе перенесите туда папку `Данные` из старой версии и запускайте новый `CopyVideoFinder.exe`.
