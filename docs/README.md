## Как поддерживается GitHub

Новая версия выпускается после успешных проверок Linux, Windows и собранного EXE. Имена ZIP и SHA-256 сохраняются для автообновления.

Workflow [«Порядок в выпусках»](https://github.com/r4v3r-63/copy-video-finder/actions/workflows/cleanup-releases.yml) обновляет описания из `docs/release-notes`, оставляет три последних стабильных выпуска и удаляет старые выпускные ZIP. Теги и история кода сохраняются. Запуск — после успешных проверок, раз в неделю и вручную; ручной запуск по умолчанию только показывает план. Черновики, предварительные и нераспознанные выпуски не удаляются.

Изменения только Markdown, снимков или макетов не запускают повторную Windows-сборку при пуше в `main`. Проверки запросов на слияние сохранены. Изменение кода, тестов или workflow запускает полную проверку.
