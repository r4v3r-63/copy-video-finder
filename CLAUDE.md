# Поиск видео для копицентров Copy.ru

Портативная программа для Windows. Ищет на бесплатных видеостоках короткие ролики о полиграфическом производстве, проверяет лицензию, даёт посмотреть и скачать подходящие и ведёт каталог покрытия по 43 техпроцессам.

Полное ТЗ: https://claude.ai/code/artifact/01bf5451-bb56-4330-8ba7-38faf84738ca

## Главное

Основной функционал — один сценарий: пользователь вводит название услуги (с подсказками из справочника 43 услуг или произвольный текст) → программа подставляет русские и английские поисковые фразы этой услуги и ищет на всех площадках → показывает только ролики с подходящей лицензией → пользователь смотрит и скачивает.

Главный экран — одно поле ввода и результаты. Каталог, статистика, пакетный поиск и экспорт — во второстепенных вкладках и делаются только после того, как основной сценарий полностью работает. Ничто не должно усложнять главный экран.

Поиск всегда идёт на двух языках — русском и английском. У каждой услуги в справочнике есть `phrases_ru` и `phrases_en`. Свободный русский текст ищется как есть и в переводе по словарю `terms_ru_en.json`; свободный английский — как есть, плюс русские фразы услуги, если он совпал с её английской фразой. Внешние сервисы перевода не используются. Запросы строит `app/query.py`.

Поиск — в первую очередь по полиграфическим услугам: свободный текст сначала сопоставляется со справочником (категория, синоним или все слова запроса в названии услуги — до 4 услуг) и ищется по их фразам; перевод по словарю — только если ни одна услуга не подошла. Выдача — только полиграфия и сувенирка: у ролика должно быть слово этой области (`topic.PRINT_DOMAIN`) и не должно быть слов чужих областей — стройка, еда, природа, музыка (`topic.FOREIGN`). Поиск площадок нечёткий, поэтому ролик показывается, только если в названии или тегах есть ВСЕ обязательные слова хотя бы одной фразы поиска (`search.is_relevant`, `topic.phrase_stems`; необязательные слова — `topic.OPTIONAL`; фраза из одного широкого слова (`topic.BROAD`: «этикетки», «календарь», «label»…, сравниваются целые слова) тему не подтверждает, кроме ключевых слов услуги (`SearchQuery.key`); слова-исключения услуги (`exclude` в справочнике, например «3d» у лазерной печати) отсеивают ролик; у Wikimedia — только по названию файла). К фразам добавляются короткие ключевые слова услуги (`key_ru`, `key_en` в справочнике). Отсеянные «не по теме» можно показать кнопкой. Отсеянные по лицензии, но подходящие по теме, длительности и размеру («все права защищены», NC, ND, не распознана) — по кнопке «Без свободной лицензии» (`SearchWorker.unlicensed_results`, решение пользователя 19.10.2026): только посмотреть (`VideoResult.view_only`) — без скачивания, без «В каталог», в покрытие не засчитываются; платные и редакционные (`licenses.is_paid`) не показываются никогда. Выдача сортируется по `relevance`: совпадения со словами запроса, затем со словами полиграфии из всех 43 услуг.

Порядок работ: этапы 1–4 из раздела 11 ТЗ — минимальная версия с полным основным сценарием; этапы 5–8 — расширения.

## Стек

- Python 3.12+
- PyQt6 (интерфейс), Qt Multimedia (встроенный плеер)
- requests (запросы к API)
- SQLite (каталог и кэш)
- FFmpeg (конвертация WebM → MP4), кладётся в папку программы
- openpyxl (экспорт Excel), Pillow (поиск похожих дублей: свой dHash в `similar.py` вместо imagehash, чтобы не тянуть numpy и scipy)
- pytest (тесты), ruff (стиль, `ruff.toml`; workflow «Проверка кода» — ruff и тесты на каждый пуш)
- PyInstaller в режиме onedir

## Каталог (этап 5)

- Ролик в каталоге — уникальная пара (площадка, ID); номер в каталоге (`videos.id`) входит в имя скачанного файла: `ID_техпроцесс_площадка_IDролика`.
- Привязки «ролик — услуга» со степенью соответствия: точное / частичное / смежный процесс / только готовая продукция.
- В панели ролика: «В каталог — лицензию проверил» (отметка «выбрано», лицензия подтверждена, привязка к услуге поиска) и «Не подходит» (отметка «отклонено», ролик больше не показывается в поиске — `SearchWorker(hidden=…)`).
- Скачивание добавляет ролик в каталог, но лицензию не подтверждает.
- Путь скачанного файла внутри папки программы хранится относительным (`paths.portable_path` / `resolve_path`, старые абсолютные переводятся при открытии каталога): папку можно перенести или запустить с флешки под другой буквой. Удалённый с площадки ролик засчитывается, только если файл на месте (`Entry.has_file`).
- Повторное скачивание: в файле лицензии — строка «Вариант файла» (качество, обрезка, звук, `downloader.variant`); другой вариант скачивается заново и заменяет файл. Докачка — только той же ссылки и с If-Range: рядом с .part — `.part.json` со ссылкой и ETag/Last-Modified первого ответа; другая ссылка (другое качество), нет валидатора или старый `.part.etag` — .part удаляется; 416 принимается, только если размер из Content-Range совпал. Файлы до 0.18 без строки варианта считаются тем же файлом, только если оба без подготовки к показу и качество совпало.
- Удаление услуги в справочнике снимает её привязки (`Catalog.drop_links`); коды с роликами в каталоге новой услуге не выдаются.
- В покрытие засчитывается (`Catalog.coverage`) только ролик не «отклонено», с лицензией «Разрешено»/«Разрешено с атрибуцией», подтверждённой пользователем, и со степенью не «только готовая продукция».
- Вкладка «Каталог» (`ui/catalog_view.py`): дерево «категория → услуга» с числом роликов и покрытием «N из цели», фильтры, карточка ролика с правкой названия, отметки, подтверждения лицензии, услуг и комментария.

## Покрытие и пакетный поиск (этап 6)

- Цвет покрытия (`catalog.coverage_level`): 0 — нет роликов, 1, 2, 3 — цель услуги выполнена; в дереве каталога и на вкладке «Покрытие».
- Вкладка «Покрытие» (`ui/coverage_view.py`): статистика ТЗ 7.2 (`catalog.statistics`) и таблица услуг.
- Пакетный поиск (`batch.py`): порядок `catalog.batch_order` — без роликов, с одним, остальные с недостатком; услуги с выполненной целью пропускаются. Поминутные лимиты пережидает (`HttpSource.max_wait` = `batch.MAX_WAIT`, запрос уходит только после ожидания), часовые — нет; паузу до `http.SHORT_WAIT` секунд (лимит «1 в секунду») ждёт и обычный поиск; одинаковые сообщения о лимитах показываются один раз. Только находит кандидатов, ничего не скачивает; ответы кэшируются, поэтому «открыть услугу» потом идёт из кэша.
- История поиска: таблица `seen` (когда ролик впервые попал в выдачу) и `searches`; «новых с предыдущего поиска» — `Catalog.new_since_previous_search`; в выдаче впервые найденные помечены «новый» (кроме самого первого поиска).

## Экспорт и импорт (этап 7)

- Меню «Каталог» (`app/export/`): реестр в Excel (лист «Реестр» + лист «Сводка покрытия») и CSV — строка на каждую привязку «ролик — услуга», все поля карточки (`registry.COLUMNS`); CSV — UTF-8 с BOM и «;» для русского Excel.
- Внешние строки — не формулы: в XLSX ячейка с «=» пишется как текст, в CSV перед «= + - @» — апостроф (при импорте снимается); так же — в выгрузке CSV из HTML-каталога (тест через node).
- Импорт CSV (`registry.import_csv`): разделитель — по строке заголовков, без столбцов «Площадка»/«ID на площадке» — ошибка; столбец есть — значение берётся даже «нет»/пустое.
- Импорт CSV (`registry.import_csv`) — перенос каталога на другой компьютер: дублей нет (пара площадка + ID), отметки, подтверждение, комментарий, привязки берутся из файла, а статус лицензии пересчитывается по таблице лицензий.
- HTML-каталог (`html_catalog.py`) — один файл, данные встроены, без внешних скриптов; фильтры, поиск, выбор, выгрузка выбранного в CSV — в браузере, без интернета (из сети только превью). Отклонённые ролики не выгружаются.
- Сводка покрытия (`summary.py`): цель выполнена, 2–3 точных ролика, где нужен поиск, площадки, что добавлено с прошлой сводки (дата — `meta.last_summary_at`).

## Дополнительно (этап 8)

- Меню «Поиск → Справочник услуг» (`ui/services_dialog.py`, ТЗ 5.1): категории, услуги, фразы, ключевые слова, исключения, цель, уровни поиска. Сохраняется в «Данные/processes.json» (`processes.save_catalog`, формат как у встроенного); код услуги при переименовании не меняется — на нём привязки каталога; новые коды — транслитом (`processes.new_id`). Недостающие поля копии (например, уровни из новой версии) берутся из встроенного справочника по коду (`load_catalog`); уровни пишутся всегда, даже пустые, чтобы удалённые не вернулись.
- Меню «Поиск»: «История поиска» (`Catalog.search_history`, повтор запроса двойным щелчком) и «Словарь перевода» (`ui/tools.py`): правки сохраняются в «Данные/terms_ru_en.json» и действуют вместо встроенного словаря (`query.Dictionary.load`).
- Плейлист M3U (`export/playlist.py`): `.m3u8` в UTF-8, только скачанные и не отклонённые ролики, пути относительно плейлиста (по умолчанию — в папке роликов).
- Проверка ссылок (`maintenance.check_links`): раз в `Settings.link_check_days` дней при запуске (0 — не проверять, дата — `meta.last_link_check_at`) и по команде меню. «Удалён с площадки» — только по `NotFoundError`; сбой сети или лимит ролик не меняет. Удалённый и не скачанный ролик в покрытие не засчитывается.
- Похожие дубли: dHash превью (`videos.phash`), пары с расстоянием до `similar.DUPLICATE_DISTANCE`; в карточке — «похож на № …».
- Зацикливание: после скачивания FFmpeg сравнивает первый и последний кадр (`downloader.loop_hint` → `videos.loop_hint`); решение пользователя — `videos.loop` в карточке.
- Кадры из ролика (`frames.py`, `ui/frames_view.FramesStrip`): кнопка в панели просмотра и в карточке каталога; FFmpeg берёт 3 кадра по ссылке просмотра (в карточке — из скачанного файла, если есть).
- Отчёт для руководства (`export/report.py`, меню «Каталог»): HTML для QTextDocument → PDF через QPdfWriter (A4), превью скачиваются в фоне (`ReportWorker`); до 3 засчитанных роликов на услугу, точные первыми. Блок услуги не разрывается между страницами (`keep_blocks_together`: верхний отступ, не PageBreak — с ним Qt теряет конец документа; после правки — `_relayout`).
- Шоурил (`export/showreel.py`, `ui/showreel_dialog.py`, меню «Каталог»): скачанные ролики услуг (не отклонённые, лицензия свободная и подтверждена — `showreel.suitable`) → один MP4 FFmpeg: по N секунд (короче `MIN_CLIP` — пропуск), 1920×1080 с полями, затемнение, без звука; рядом .txt с авторами и лицензиями (`credits_text`). Превью отчёта — JPEG 16:9 через Pillow (`report.thumb_jpeg`: Qt не читает AVIF Coverr).
- Подготовка к показу: `Settings.trim_seconds` (0 — не обрезать) и `Settings.mute_audio`; при скачивании FFmpeg перекодирует в MP4 с `-t`/`-an` (`DownloadJob.trim/mute`), в файле лицензии — пометка, что ролик изменён.
- Новые столбцы `videos` добавляются в старую базу через `ALTER TABLE` (`catalog._ADDED_COLUMNS`).

## Дизайн-система

- Стиль Copy.ru: технологичный минимализм, нейтральные поверхности, синий `#246BEE` — главные действия и активные элементы, фиолетовый `#7B35B5` — редкие акценты, шрифт Inter. Коды ориентировочные (по маркетинг-киту); основную цветовую концепцию без согласования не менять.
- Все цвета, размеры, скругления и шрифты — только в `app/design.py` (`PALETTES` светлой и тёмной темы). HEX-коды в остальном коде запрещены (тест `test_no_colors_outside_tokens`).
- `app/ui/theme.py` собирает из токенов стиль Qt с состояниями hover, focus, pressed, disabled. Кнопкам назначается роль `theme.set_role(button, PRIMARY | SECONDARY)` (по умолчанию — tertiary), панелям — `theme.make_card`. Кнопка по умолчанию в диалогах выглядит как primary.
- Минимальная ширина окна — максимум по всем вкладкам, и скрытым тоже: списки — `theme.compact_combo` (ширина не от самого длинного пункта), панели каталога — с явной `setMinimumWidth`. Тест `test_catalog_tab_does_not_widen_window`.
- HTML-экспорт берёт те же токены: `design.css_variables()`.
- Тема — `Settings.theme`: `system` (по Windows), `light`, `dark`. Контраст по WCAG AA проверяет `tests/test_design.py`.

## Уровни поиска и интернет

- У каждой услуги в справочнике, кроме фраз по названию, есть `levels`: оборудование → действие → отдельные этапы → похожие операции, фразы на en/ru/de/fr. Следующий уровень запускается, только если подходящих роликов меньше `search.ENOUGH`. Ролик проверяется фразами только уже запущенных уровней, а степень соответствия (`VideoResult.match_hint`) — по самому раннему уровню, фраза которого совпала (`SearchWorker.matched_level`), а не по запросу, который его вернул; так «смежный процесс»/«частичное» и предлагается в каталог, в панели видно, по какому запросу он нашёлся (`found_by`).
- Фильтр темы считает словами полиграфии и термины всех услуг (`search.print_stems`, без `topic.NOT_PRINT` — wire, metal, board…). Тест `test_level_phrases_pass_own_topic_filter`: ролик, названный как любая фраза уровня, проходит фильтр — новые фразы проверять им.
- `Source.languages` — языки площадки, `Source.max_level` — до какого уровня ей слать запросы (Coverr — 1, интернет — 2).
- Интернет (`WebSource`): DuckDuckGo и Brave получают запрос + «free stock video» (de/fr — свои слова), страницы известных площадок открываются их модулями (`known_site`), прочие — по Open Graph/schema.org: нужен файл ролика и ссылка на Creative Commons, иначе ролик не показывается. Лицензия `VideoObject` главнее страницы: свои условия ролика («все права защищены») ссылкой из подвала не подменяются; лицензия страницы (`rel="license"` или просто ссылка CC) с роликом не связана — только «Требует проверки». Ссылка CC распознаётся только на домене creativecommons.org (`licenses.name_from_url` разбирает URL). YouTube, Mixkit, платные стоки и соцсети пропускаются (`SKIP_DOMAINS`). Поисковики (`web.Engine`) перебираются по очереди: Tavily (бесплатно 1000 в месяц, ключ без карты; `TAVILY_MONTHLY` = 900), Brave (платный, кредит $5 в месяц; `BRAVE_MONTHLY` = 900), DuckDuckGo без ключа. Пользователь просил только бесплатные варианты: месячные пределы не должны выходить за бесплатный объём (тест `test_free_limits_stay_free`). Поисковик при капче/«anomaly» отдыхает 10 минут, блокировку не обходим. Bing не используется: программам он отдаёт подменённую выдачу. Tavily ищет только по `web.FREE_STOCK_DOMAINS` (как «site:»), запрос без «free stock video» — иначе в выдаче страницы поиска стоков. Pexels туда не входит (403 для программ, ключей не выдаёт). Проверено вживую: по узким услугам поисковик находит десятки роликов, но ~3/4 без свободной лицензии — они видны по кнопке «Без свободной лицензии». Videvo теперь перенаправляет на Freepik — не подключается.

## Интерфейс источника

Каждая площадка реализует `Source` из `sources/base.py`:

- `search(query, filters, page, lang) -> list[VideoResult]` — `lang` (`ru`/`en`/`de`/`fr`) передаётся в параметр языка API (Pexels `locale`, Pixabay `lang`); на каких языках площадка ищет — `Source.languages`
- `get_details(source_id) -> VideoResult`
- `get_license(result) -> LicenseInfo`

`VideoResult` содержит: площадку, ID на площадке, название, описание, превью, длительность, ширину, высоту, наличие звука, URL страницы, список файлов для скачивания (качество + URL из API), автора и ссылку на автора.

Уникальность ролика определяется парой (площадка, ID на площадке).

Площадка без ключа API (`is_configured() == False`) в поиске пропускается, пользователь видит это как подсказку, а не как ошибку. Pexels с октября 2026 временно не выдаёт новые ключи, поэтому основные площадки — Pixabay и Wikimedia Commons; модуль Pexels остаётся и включается, как только в настройках появится ключ.

Coverr: длительность в ответе — строка; `is_premium` → «Coverr Premium» → «Отклонено»; `is_ai_generated` — пометка в лицензии; страница ролика — `https://coverr.co/videos/<slug>`. Лицензия Coverr License (коммерческое использование без атрибуции; запрещены перепродажа и обучение ИИ); скачивать только по `urls.mp4_download` — так Coverr учитывает скачивания, просматривать по `mp4_preview` (`VideoResult.preview_video`). Площадка ищет только по-английски (`Source.languages`), русские фразы ей не отправляются.

Europeana: ключ (секрет `EUROPEANA_API_KEY`), только открытые лицензии, лицензия — по ссылке в `rights` (`licenses.name_from_url`); в поиске нет длительности. Internet Archive: advancedsearch, только `licenseurl` CC/PD, без `youtube-*` (правило 5); ссылки на файлы не собираются (правило 2) — ролик скачивают на странице; тема — по названию. Только горизонтальные ролики (`SearchFilters.orientation = "landscape"`: ширина больше высоты; вертикальные и квадратные отсеиваются). Предел длительности по умолчанию — 180 с (раньше 45; при загрузке старых настроек 45 поднимается до 180, `SETTINGS_VERSION`).

Vimeo: личный токен с правами public, поиск `filter=CC`, лицензия каждого ролика из поля `license` (NC/ND — «Отклонено»). Ссылки на файлы (`download`) Vimeo отдаёт не для всех роликов; если их нет, кнопка «Скачать» недоступна, а в лицензии пометка «скачайте на странице ролика». Ссылки на файлы Vimeo не конструировать. Проверено вживую: для чужих CC-роликов `download` пуст, CC-ролики обычно длиннее 45 с; лимит бесплатного приложения — 50 запросов в минуту. Тема у Vimeo проверяется только по названию (теги ненадёжны). Ролики без ссылки на файл стоят в конце выдачи с пометкой «скачать на сайте».

## Жёсткие правила

1. В первую очередь — официальные API площадок. По решению пользователя (19.10.2026) разрешены также поиск по интернету (`sources/web.py`: поисковики по очереди: Tavily по бесплатному ключу, Brave по ключу, без ключа — DuckDuckGo) и чтение страниц сайтов без API (`sources/videezy.py`, любые страницы с роликом и открытой лицензией в разметке). Страницы читать бережно: свои лимиты, кэш 24 ч, блокировку поисковика не обходить.
2. Никогда не конструировать URL файлов: только ссылки из ответа API, со страницы ролика (Videezy — из кнопки скачивания в сессии сайта, `resolve_download`) или вставленные пользователем.
3. Соблюдать лимиты: Pexels — 200 запросов в час и 20 000 в месяц; Pixabay — около 100 в минуту, ответы кэшировать 24 часа. Лимиты не обходить.
4. Возле результатов Pexels и Pixabay всегда показывать ссылку на площадку.
5. Mixkit и YouTube не подключать.
6. Лицензии с NC и ND, а также Editorial, Personal, Premium и платные — всегда «Отклонено».
7. Нераспознанная лицензия или голое «Royalty Free» — «Требует проверки»; в покрытие не засчитывается.
8. Ролики со степенью «только готовая продукция» в покрытие техпроцесса не засчитываются.
9. Программа ничего не пишет в реестр и системные папки. Все данные, настройки, ключи API, кэш и журнал хранятся в папке «Данные» рядом с exe (в режиме разработки — рядом с main.py).
10. API-ключи не хранить в коде и не коммитить. Встроенные ключи — только через секреты репозитория (`PIXABAY_API_KEY`, `VIMEO_TOKEN`, `COVERR_API_KEY`, `PEXELS_API_KEY`, `EUROPEANA_API_KEY`, `TAVILY_API_KEY`, `BRAVE_API_KEY`): сборка пишет их в `defaults.json` рядом с exe, программа берёт их через `Settings.key()`, ключ из настроек пользователя главнее. Тест `test_no_api_keys_in_repository` следит, чтобы ключи не попали в код.

Выпуск версии: обновить `__version__` в `app/__init__.py`, затем запустить workflow «Сборка для Windows» с полем «version» (Actions → Run workflow, или `gh api -X POST repos/r4v3r-63/copy-video-finder/actions/workflows/build.yml/dispatches -f ref=main -f inputs[version]=X.Y.Z`). Workflow сам создаст тег vX.Y.Z и выпуск в Releases. Тег `v*`, отправленный вручную, работает так же; из облачного сеанса Claude отправка тегов запрещена. Старые выпуски удаляет workflow «Удаление старых выпусков» (`cleanup-releases.yml`, только вручную): оставляет `keep` последних, по умолчанию `dry_run=true` — только список; удаляет с `dry_run=false` (из облачного сеанса выпуски напрямую удалять нельзя).

## Сборка и поставка

- Автообновление: при запуске программа смотрит `releases/latest` (репозиторий публичный, ключ не нужен) и предлагает обновиться. ZIP скачивается в «Данные/update», сверяется с `.sha256` из выпуска, распаковывается; `update.cmd` ждёт выхода программы, копирует файлы `robocopy /E` (без удаления) и запускает её снова. «Данные» не трогаются. Поэтому имя ассета `CopyVideoFinder-vX.Y.Z-windows.zip` и файл `.sha256` рядом менять нельзя.

- Только PyInstaller onedir. Однофайловый exe не делать: Касперский принимает его за троян.
- FFmpeg и все зависимости — внутри папки сборки.
- GitHub Actions на windows-latest собирает ZIP и публикует его в Releases.

## Как работать

- Разработка идёт по этапам из раздела 11 ТЗ. Каждый этап заканчивается программой, которая запускается и проверяется.
- Новая логика лицензий, дублей и статистики сопровождается тестами на фикстурах из tests/fixtures, без обращений к сети.
- Фоновые потоки при закрытии окна отменяются и дожидаются полностью (`closeEvent`, `FramesStrip.stop`, `UpdateController.stop`): поток, переживший окно-родитель, роняет программу. Долгие внешние процессы (FFmpeg) — через Popen с опросом отмены.
- Тесты окон: одно `QApplication` на весь прогон создаёт `tests/conftest.py` (режим offscreen); своё приложение Qt в тестах не создавать.
- Интерфейс и сообщения пользователю — на русском языке.
